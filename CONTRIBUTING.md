# Contributing

Contributions should improve discoverability without weakening evidence quality.

## Before submitting

- Identify the repository or project record being changed.
- Supply a canonical source URL and the date it was checked.
- Separate direct observations from interpretation.
- Do not submit secrets, personal data, private repository content, or scraped material without a lawful basis.
- Do not claim a capability exists unless the relevant code or documentation demonstrates it.

## Validation

Run:

```bash
python tools/validate_registry.py
python tools/render_summary.py
```

## Review standard

Changes to ownership, visibility, trust, security, or capability claims require a source reference and human review. Atlas maintainers may reject unsupported claims or retain them with an explicit uncertainty label.
