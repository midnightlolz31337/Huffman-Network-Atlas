# Security policy

Do not report vulnerabilities in public issues. Until a dedicated private reporting channel is configured, contact the repository owner through the GitHub profile and include only the minimum information needed to establish contact; do not include exploit payloads or sensitive personal data in a public issue.

The Atlas is an index, not an execution service. Reports about indexed projects should be directed to their respective maintainers. Do not submit secrets, credentials, private data, or non-public repository contents.
