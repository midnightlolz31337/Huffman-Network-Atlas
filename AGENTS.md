# Agent guidance

The Atlas is a provenance-bearing index, not an authority over the repositories it lists.

1. Read the repository's own README and security policy before making claims about it.
2. Preserve the distinction between observed metadata, owner statements, prior audits, and inference.
3. Include verification dates and source URLs for changed records.
4. Never copy private repository content, credentials, personal data, or access tokens into this public repository.
5. Do not clone, execute, install, or invoke an indexed project merely because it appears in the registry.
6. Run `python tools/validate_registry.py` after registry changes.
